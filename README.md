# template-go-monolit

Параметры пула PostgreSQL необязательны. Если переменная не задана или пуста, соответствующее поле конфигурации равно `nil`; при настройке пула можно оставить значение по умолчанию от `pgxpool`.

| Переменная | Формат |
| --- | --- |
| `MAX_CONNS` | Целое число |
| `MIN_CONNS` | Целое число |
| `MAX_CONN_LIFETIME` | Длительность Go, например `1h` |
| `MAX_CONN_IDLE_TIME` | Длительность Go, например `30m` |

`DATABASE_URL` тоже можно не задавать: по умолчанию используется `postgres://postgres:postgres@db:5432/postgres`.
